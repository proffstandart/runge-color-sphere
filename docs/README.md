# GitHub Pages: страница политики конфиденциальности

Файл `docs/privacy-policy.html` — готовая страница политики (RU/EN). URL нужен для
RuStore и для ссылки из README.

## Включение (делает владелец аккаунта)

1. Запушьте репозиторий на GitHub.
2. Откройте репозиторий → **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Ветка: **main**, папка: **/docs** → **Save**.
5. Через 1–2 минуты страница будет доступна по адресу:

```
https://<ваш-логин>.github.io/<имя-репозитория>/privacy-policy.html
```

Например, если репозиторий называется `runge-color-sphere`:
`https://<ваш-логин>.github.io/runge-color-sphere/privacy-policy.html`

## Перед публикацией

- В `privacy-policy.html` замените `[укажите e-mail]` / `[your email]` (два места,
поиск по «укажите e-mail») на реальный адрес для вопросов конфиденциальности.
- Проверьте страницу локально: откройте файл в браузере — она полностью автономна
(нет внешних ссылок, скриптов и относительных путей).

## Что прописать в RuStore

В консоли RuStore (раздел ссылок на документы) укажите полный URL страницы
из шага 5.
