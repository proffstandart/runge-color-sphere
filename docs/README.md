# Политика конфиденциальности

Политика публикуется **отдельно от репозитория приложения**:

- репозиторий: `proffstandart/privacy`
- страница: https://proffstandart.github.io/privacy/

Этот адрес указывается в карточке RuStore и в README приложения.
Отдельный репозиторий выбран специально: приложение можно пересоздавать
и переоформлять, ссылка в магазине при этом остаётся рабочей.

Файл `privacy-policy.html` в этой папке — копия страницы для истории.
Публиковать его из репозитория приложения не нужно: Pages уже настроены
в репозитории `proffstandart/privacy`.

При изменении текста политики правьте `index.html` в репозитории `privacy`
и обновляйте копию здесь, чтобы версии не расходились.
